# Dashboard screenshots after the 2026-11-11 update

These six screenshots show the **current** dashboard. They were produced by `scripts/e2e-mock-journey.mjs` (real Chrome, a throwaway database, **mock** PayPal, the rule-based buyer, the local seller simulator, synthetic data). **No PayPal request and no model request was made to produce them, and none of them shows a real Sandbox transaction.** The mock order and payment ids that appear (for example `ORD7C3041A29F1`) are generated by the in-memory mock.

The real Sandbox payment and the real Groq negotiation are documented in [docs/submission/](../../submission/); their screenshots there were captured with the dashboard layout used before this update (same data and decisions, earlier layout). The 25 screenshots in `docs/qa/final-playwright-e2e/mock/` also show the earlier layout.
